## Моё объяснение

`[Чтобы внести срочное исправление, не теряя текущих наработок, мы используем git stash push -u: команда сохраняет все незакоммиченные изменения и очищает рабочую папку. После hotfix возвращаем изменения командой git stash apply --index — она не только накладывает их поверх hotfix, но и восстанавливает исходное состояние индекса (какие файлы были staged, а какие нет). Важно помнить: apply не удаляет запись из stash, поэтому после проверки её нужно убрать вручную через git stash drop.]`

Ожидаемый ответ: `-u` сохраняет untracked, `--index` восстанавливает staging, apply оставляет запись stash.
